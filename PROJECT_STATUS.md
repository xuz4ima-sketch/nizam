# PROJECT_STATUS — НИЗАМ

Обновлено: 2026-10-14. Версия 1.0 (этапы А, Б, В выполнены; Г — не начат).

## 1. Что реализовано
- **Этап А**: проект Vite + React 19 + TS + Tailwind 4; навигация (боковое меню ≥768px, нижнее меню на телефоне); главная панель; создание / редактирование / удаление задач; выполнение; IndexedDB (Dexie); планировщик (Сегодня/Завтра/Неделя/Календарь/Все).
- **Этап Б**: повторения (ежедневно, дни недели, интервал, дата окончания) с отдельными экземплярами; привычки; учебные направления; частичный прогресс; цели (темп, остаток); таймер (свободный, Pomodoro, 5 минут) на временных метках; причины пропусков; экспорт/импорт JSON с проверкой структуры; демо-план одной кнопкой.
- **Этап В**: графики (Recharts) на реальных данных; сравнение недель; обзор дня и недели; рекомендации по прозрачным правилам; «Минимальный день»; восстановление (перенос только по согласию, окно 7 дней); компенсация норм (opt-in, лимит); тёмная тема; PWA (manifest, service worker, иконки); автотесты; README.
- Раздел «Поклонение» (добровольный, без генерации религиозного контента).

## 2. Что проверено (реально запущено)
- `npm run build` — проверка типов (TypeScript 7) и сборка: без ошибок.
- `npm test` — 26 тестов Vitest пройдены: даты и часовые пояса, серии, перенос/удаление одного дня, просрочка, частичный прогресс, 120 мин/30 мин = 25%, 45→37,5%→62,5%, темп цели, серии привычек, свободные окна, отсутствие двойного счёта, каскадное удаление, таймер старт→пауза→продолжение→завершение, экспорт→очистка→импорт, отклонение битых файлов, пустая база.
- Ручная проверка в браузере (Playwright, Chromium, production-сборка):
  - 390px: пустая база без ошибок; задача создана → перезагрузка → осталась; частично 30/120 мин → 25% на главной; повторяющаяся задача видна во «Завтра»; таймер пережил перезагрузку на паузе и продолжился; нет горизонтальной прокрутки.
  - Демо-план; запись 45 мин в «Перевод арабской книги» → 37,5%, осталось 75.
  - 1280px + тёмная тема; все 11 разделов открываются без ошибок в консоли.
  - Цель «Прочитать книгу»: 300 стр., 50 прочитано, 5 дней → 50 стр./день.
  - Экспорт JSON → «Удалить все данные» → импорт → 8 задач, 7 направлений, 1 цель восстановлены.
- Найдено и исправлено при проверке: дата создания направления бралась по UTC (неверные «дневные нормы»); устаревшие модули после обновления (добавлена автоперезагрузка); заглавные буквы в названиях месяцев; контраст столбцов графика.

## 3. Что не сделано / ограничения
- Не проверено на реальном телефоне и в Safari/iOS (только эмуляция ширины в Chromium).
- Установка PWA и офлайн-режим требуют HTTPS-хостинга — не опубликовано (нужна ваша авторизация).
- Уведомления — только звук и системное уведомление при открытой вкладке; фоновых напоминаний нет.
- Блокировать другие приложения телефона веб-приложение не может (в интерфейсе сказано честно).
- Этап Г: облачная синхронизация, аккаунты, ИИ-наставник — не начаты (`.env.example` подготовлен).
- Нет E2E-тестов в репозитории (UI проверялся вручную через Playwright).
- Язык только русский; поле «Язык» в настройках зафиксировано.

## 5. Как продолжить
1. Облако: реализовать адаптер синхронизации за `src/db/repo.ts` (Supabase: таблицы = таблицы Dexie, поле `updatedAt` для разрешения конфликтов), авторизация через Supabase Auth.
2. Добавить E2E-тесты (Playwright) для сценариев 1–10 из ТЗ.
3. Напоминания через Push API (нужен сервер) или локальные уведомления в нативной оболочке (Capacitor).
4. Миграции схемы: увеличить `SCHEMA_VERSION` и добавить `this.version(2)` в `src/db/db.ts`.
