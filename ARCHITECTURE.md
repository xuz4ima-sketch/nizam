# Архитектура НИЗАМ

React 19 + TypeScript + Vite 8 + Tailwind CSS 4, Dexie (IndexedDB), Recharts, Lucide, vite-plugin-pwa. Без сервера: всё работает в браузере.

## Структура

```
src/
  db/          schema.ts — типы сущностей и настройки по умолчанию
               db.ts     — Dexie, таблицы и индексы
               repo.ts   — ЕДИНСТВЕННАЯ точка изменения данных (валидация, транзакции)
               backup.ts — экспорт / проверка / импорт JSON
               seed.ts   — пример учебного плана
  lib/         чистая бизнес-логика без React (покрыта тестами):
               dates.ts (часовой пояс, хиджра, 12/24 ч), recurrence.ts (серии → экземпляры),
               progress.ts (направления, цели), streaks.ts (серии привычек), stats.ts (аналитика),
               slots.ts (свободные окна, раскладка и пересечения в календаре), quickadd.ts (разбор быстрого ввода),
               notices.ts (уведомления), recommend.ts (правила недельных рекомендаций),
               reminders.ts (проверенные аяты/хадисы с источниками), validate.ts, labels.ts, install.ts (PWA)
  state/       data.tsx — live-запрос ко всей базе (useLiveQuery) + «сейчас» (тик 20 с); useData(), useInstances()
  components/  ui.tsx (Modal, Toast, Ring, ProgressBar, Tabs…), Layout.tsx (меню, шапка, поиск, уведомления),
               TaskItem / TaskForm, charts.tsx (цвета темы, мини-календарь), WeekChart.tsx (ленивый), Art.tsx, habitIcons.tsx
  pages/       Dashboard, Planner (Задачи), Calendar, Habits, Study (+ «Поклонение»), Goals, Focus,
               Recovery, Stats, History, Review, Settings
tests/         logic.test.ts, repo.test.ts (fake-indexeddb), quickadd.test.ts
```

## Хранение данных

| Таблица | Назначение |
|---|---|
| `tasks` | Задача или серия (шаблон): дата начала, время, длительность, категория, приоритет, повторение, связь с целью/направлением |
| `occurrences` | Состояние конкретного дня серии, `id = taskId|дата`: статус, перенос, правки одного дня, причина пропуска |
| `sessions` | **Единственный источник фактического времени и объёма** (таймер, ручная запись, отметка задачи) |
| `areas` | Учебные направления: единица (мин/стр./уроки/главы/слова), дневная и недельная норма, общая цель |
| `habits`, `habitLogs` | Привычки (иконка, цвет, норма) и отметки по дням (`habitId|дата`) |
| `goals` | Цели: целевой объём, начальное значение, источник прогресса (вручную / направление / задачи), сроки |
| `reviews`, `settings`, `timer` | Обзоры дня, настройки, состояние текущего таймера |

Ключевые решения:
- **Повторения без размножения записей.** Экземпляры вычисляются на лету (`expand`), в базу пишется только то, что изменилось в конкретный день. Перенос или удаление одного дня не трогает серию.
- **Без двойного счёта.** Отметка «выполнено» дописывает к таймеру одну сессию-дополнение с фиксированным id (перезаписывается, а не суммируется).
- **Таймер по меткам времени** (`runningSince`, `accumulatedMs`) хранится в базе — переживает перезагрузку, сон устройства и переключение вкладок.
- **День пользователя** считается в выбранном часовом поясе (`zonedParts`), даты хранятся строками `YYYY-MM-DD`.
- **Статистика только из данных.** Все показатели — функции от таблиц; демо-цифр нет.
- **Миграции:** новые поля необязательны (настройки сливаются с `DEFAULT_SETTINGS`), поэтому старые базы и резервные копии читаются без миграции. Для изменения индексов — `this.version(2)` в `db.ts` и увеличить `SCHEMA_VERSION`.

## Интерфейс

- Дизайн-токены — CSS-переменные в `index.css` (светлая и тёмная тема), подключены к Tailwind через `@theme inline`. Recharts получает фактические цвета через `useThemeColors()`.
- Шрифты Manrope (кириллица) и Noto Naskh Arabic подключены локально (@fontsource) — работают офлайн.
- Компоновка: ≥1024 px — боковое меню и верхняя панель; меньше — шапка и нижняя навигация (Главная / Задачи / Фокус / Статистика / Ещё). Главная на телефоне — отдельная компоновка, а не уменьшенная версия.
- Разделы, кроме главной и задач, загружаются лениво; Recharts не входит в первый экран.
- Поддержка `prefers-reduced-motion`, фокус с клавиатуры, подписи `aria-*`, безопасные области экрана (`env(safe-area-inset-*)`).

## Расширение до облачной версии

Все изменения проходят через `src/db/repo.ts`, чтение — через `state/data.tsx`. Для синхронизации (например, Supabase): таблицы 1:1 с Dexie, поле `updatedAt` для разрешения конфликтов, адаптер за `repo.ts`, авторизация — Supabase Auth. Переменные окружения описаны в `.env.example`.
