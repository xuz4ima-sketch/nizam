# НИЗАМ — نِظَام

**Порядок. Дисциплина. Постоянство. Развитие.**

Персональная система дисциплины: задачи и расписание, привычки, учебные направления, цели, режим концентрации (Pomodoro), восстановление после срывов, статистика и обзоры. Работает полностью локально, без платных API. Данные хранятся в браузере (IndexedDB) и сохраняются после перезагрузки. Устанавливается на телефон как PWA и работает офлайн.

## Запуск

Нужен Node.js 20+ (проверено на Node 24).

```bash
cd nizam
npm install        # установка зависимостей
npm run dev        # режим разработки: http://localhost:5173
```

Production-сборка:

```bash
npm run build      # проверка типов + сборка в dist/
npm run preview    # локальный просмотр сборки: http://localhost:4173
npm test           # автотесты (Vitest)
```

### Открыть на телефоне
1. Запустите `npm run dev -- --host` (или `npm run preview -- --host`) на компьютере.
2. Откройте на телефоне `http://<IP-компьютера>:5173` в той же Wi-Fi-сети.
3. Для установки как приложения и офлайн-режима (service worker) браузеры требуют HTTPS — разместите `dist/` на любом статическом хостинге (см. ниже).

### Публикация (нужна ваша авторизация)
Папка `dist/` — обычный статический сайт (маршруты через `#`, поэтому настройка сервера не нужна). Варианты:
- **Netlify Drop**: перетащите `dist/` на https://app.netlify.com/drop.
- **Vercel / Cloudflare Pages / GitHub Pages**: сборка `npm run build`, папка публикации `dist`.

Сайт пока не опубликован — для этого нужен ваш аккаунт на одном из сервисов.

## Резервное копирование
Данные живут только в этом браузере на этом устройстве. Чтобы не потерять их:
1. **Настройки → Резервная копия → Экспорт в JSON** — скачивается файл `nizam-backup-ГГГГ-ММ-ДД.json`.
2. Храните файл в облаке или на другом устройстве. Делайте копию раз в неделю (главная панель напомнит).
3. **Импорт из JSON** — восстанавливает все данные из файла (структура проверяется; текущие данные заменяются после подтверждения).

Так же переносятся данные между устройствами. Очистка данных сайта в браузере удаляет базу — сначала сделайте экспорт.

## Возможности
- **Главная**: дата, приветствие, прогресс дня, ближайшее занятие, три главные задачи, план и факт времени, выполнено / не завершено / пропущено, прогресс целей и направлений.
- **Планирование**: Сегодня, Завтра, Неделя, Календарь, Все задачи. Повторения: ежедневно, по дням недели, каждые N дней, с датой окончания. Изменение, перенос и удаление одного дня не затрагивают серию. Выполнено / частично (по фактическому времени) / пропуск с причиной / перенос / отмена. Предложение свободного времени — только по нажатию.
- **Привычки**: цели в минутах, страницах, повторениях или «да/нет»; ежедневные или N раз в неделю; дни отдыха и уважительные пропуски; серии и соблюдение считаются по реальным отметкам.
- **Обучение**: направления с дневной нормой, недельным планом и общей целью; учёт минут/страниц/уроков; история, статистика по неделям и месяцам; компенсация недовыполненного (включается для каждого направления, с лимитом и подтверждением).
- **Цели**: ежедневные, недельные, месячные, долгосрочные; прогресс вручную, из направления или из выполненных задач; остаток, необходимый темп, отставание.
- **Фокус**: свободный таймер, Pomodoro, «Начни с 5 минут»; пауза/продолжение; запись отвлечений; история. Время считается по временным меткам и переживает перезагрузку.
- **Восстановление**: «Начни с 5 минут», «Минимальный день», невыполненное за 7 дней с переносом по согласию, анализ причин пропусков.
- **Статистика**: 7/30 дней, графики план/факт и минут, сравнение недель, стабильные привычки, откладываемые занятия.
- **Обзор**: дневной (4 вопроса + оценка) и недельный с рекомендациями по прозрачным правилам.
- **Поклонение**: добровольный раздел для личных норм и привычек. Приложение не генерирует аяты, хадисы и постановления.
- Светлая/тёмная тема, часовой пояс (по умолчанию Africa/Cairo), адаптивность, доступность с клавиатуры.

## Структура
```
src/
  db/        schema.ts (типы), db.ts (Dexie), repo.ts (все изменения данных), backup.ts, seed.ts (демо-план)
  lib/       dates.ts (часовые пояса), recurrence.ts (серии и экземпляры), progress.ts, streaks.ts,
             stats.ts, slots.ts, recommend.ts, validate.ts, labels.ts
  state/     data.tsx — единый live-источник данных для всех экранов
  components/ ui.tsx, Layout.tsx, TaskForm.tsx, TaskItem.tsx
  pages/     Dashboard, Planner, Habits, Study (+ «Поклонение»), Goals, Focus, Recovery, Stats, Review, Settings
tests/       logic.test.ts, repo.test.ts
```

### Ключевые решения модели данных
- `Task` — шаблон (одиночная задача или серия). `Occurrence` (`id = taskId|дата`) хранит статус и изменения конкретного дня.
- Фактическое время и объём хранятся **только** в `StudySession`. Отметка «выполнено» дописывает одну сессию-дополнение (перезаписывается, а не суммируется), поэтому прогресс не считается дважды.
- Все изменения идут через `src/db/repo.ts` — для облачной синхронизации (Supabase/PostgreSQL) достаточно добавить адаптер за этим модулем.
