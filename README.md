# НИЗАМ | نِظَام

**Порядок. Постоянство. Развитие.**

Персональная система дисциплины, обучения и самоорганизации: задачи и календарь, привычки, учебные направления, цели, режим концентрации (Pomodoro), восстановление после пропусков, статистика и история. Раздел «Знание»: Мусхаф, перевод смыслов Кулиева и тафсир ас-Саади, хадисы аль-Бухари и Муслима, мутуны с режимом заучивания и классические книги. Интерфейс на русском, арабском (справа налево) и английском. Работает полностью в браузере, без регистрации и платных сервисов. Данные хранятся на устройстве (IndexedDB) и не теряются при перезагрузке. Устанавливается на телефон и компьютер как приложение (PWA) и работает без интернета.

**Открыть:** https://xuz4ima-sketch.github.io/nizam/

## Как пользоваться

1. **Первый запуск.** На главной нажмите «Создать задачу» или «Установить пример плана» (Коран, арабский язык, перевод, программирование и др. — редактируемый образец).
2. **Быстрое добавление.** В разделе «Задачи» введите строку: `Арабский язык — 60 минут`. Понимаются длительность (`90 мин`, `1,5 ч`), время (`в 7:30`), `завтра`, категория (`#Языки`) и `!` — «важно». «Подробнее» открывает полную форму (повторения, цель, направление, заметки).
3. **Выполнение.** Квадрат слева от задачи — «выполнено». Меню «⋯» — частичное выполнение (по фактическому времени), перенос с подсказкой свободного окна, пропуск с причиной, редактирование одного дня или всей серии, удаление.
4. **Концентрация.** «Начать занятие» на главной или раздел «Фокус»: свободный таймер, Pomodoro, «Начни с 5 минут». Во время сеанса экран очищается — только название, таймер и кнопки. Время считается по реальным меткам: перезагрузка и переключение вкладок его не теряют.
5. **Вечером** — «Статистика» (день / неделя / месяц, отчёт за неделю) и «История».
6. **Тяжёлый день?** «Оставить только главное» на главной или раздел «Восстановление».

Поиск — `Ctrl + K` (или `/`), на телефоне — значок лупы.

## Раздел «Знание»

- **Коран → Мусхаф.** 604 страницы мединского мусхафа (письмо Усмани), на весь экран; размер шрифта, ночной режим, перелистывание жестом и стрелками, переход к суре/джузу/странице, закладки. «Сохранить весь Мусхаф» — для чтения без интернета.
- **Коран → с переводом и тафсиром.** Аят за аятом: арабский текст, перевод смыслов Э. Кулиева (или Saheeh International в английском интерфейсе), тафсир ас-Саади на русском или арабском, аль-Муяссар. Отдельные размеры шрифта для Корана, перевода и тафсира. Чтение Мишари аль-Афаси с повтором аята для заучивания, закладки и копирование аята со ссылкой.
- **Хадисы.** Подборка «Время и порядок жизни» (аль-Бухари, Муслим, ат-Тирмизи — с номерами и оценками) и полные «Сахих» аль-Бухари и Муслима по книгам: арабский текст с иснадом, перевод, поиск по номеру и словам, закладки, размер шрифта.
- **Мутуны.** «Три основы», «Четыре правила», «Нарушители ислама», «Кашф аш-шубухат», «аль-Васитыйя», «ат-Тахавийя», «Люм‘ат аль-и‘тикад», «Сорок хадисов ан-Навави», «аль-Байкуния», «аль-Аджуррумийя», «Тухфат аль-атфаль», «аль-Джазария». Режим заучивания: скрыть выученное или всё (с подсказкой первого слова), счётчик повторов, отметка «выучено», прогресс; повторение отрывка N раз; озвучка голосом устройства, запись своего голоса для каждой строки, прикреплённая запись шейха/учителя с повтором фрагмента A–B и замедлением.
- **Книги.** Те же тексты в формате чтения: оглавление, размер шрифта, запоминание места.

Источники: Quran.com API (текст, переводы, тафсиры, аудио), fawazahmed0/hadith-api (хадисы), арабская Викитека CC BY-SA 4.0 (тексты мутунов; у каждого текста — ссылка на версию). Тексты не набираются вручную: их собирают скрипты из `scripts/texts` и `scripts/hadith`.

## Языки

Переключатель языка — в шапке (значок 文A) и в «Настройках»: русский, العربية (интерфейс справа налево), English. Данные пользователя (названия задач и т. п.) не переводятся.

## Резервная копия (важно)

Данные живут только в этом браузере на этом устройстве.
- **Настройки → Резервная копия → Экспорт в JSON** (или меню профиля → «Скачать резервную копию»). Делайте раз в неделю — приложение напомнит.
- **Импорт из JSON** восстанавливает данные (файл проверяется; текущие данные заменяются только после подтверждения). Так же переносятся данные на другое устройство.
- Очистка данных сайта в браузере удаляет базу — сначала сделайте экспорт.

## Установка как приложения

- **Android / Chrome / Edge:** Настройки → «Установить НИЗАМ» или меню браузера → «Установить приложение».
- **iPhone / iPad (Safari):** «Поделиться» → «На экран „Домой“».

## Разработка

Нужен Node.js 20+ (проверено на Node 24).

```bash
npm install        # зависимости
npm run dev        # разработка: http://localhost:5173
npm test           # автотесты (Vitest)
npm run build      # проверка типов + сборка в dist/
npm run preview    # просмотр сборки: http://localhost:4173
node scripts/e2e/smoke.mjs <адрес> chromium|webkit 390   # сквозная проверка сайта
```

**Публикация.** Каждый `git push` в ветку `main` запускает GitHub Actions (`.github/workflows/deploy.yml`): тесты → сборка → GitHub Pages. Папка `dist/` — обычный статический сайт (маршруты через `#`, базовый путь относительный), её можно разместить на любом хостинге.

Устройство проекта — в [ARCHITECTURE.md](ARCHITECTURE.md), состояние и план — в [PROJECT_STATUS.md](PROJECT_STATUS.md).
